# 알림 SSE 응답 예시 (설계 기록 보정)

> 예약 API 명세가 아니라 타입별 알림 payload 예시를 보존한 문서입니다. 게시 코드 `3865b451663788792d7e78c736282f8b9ff105f1`의 SSE 봉투 필드와 대조했습니다. 실제 전송 캡처/운영 검증 결과가 아닙니다. 아래 ID·이름·시각은 예시입니다. JSON은 SSE의 `data` 내용이며 `id: {memberId}_{seq}`, `event: {NotificationType}`은 별도 SSE 필드입니다. 최초 PING/heartbeat에는 이 봉투를 사용하지 않습니다.

> `SseEnvelope.createdAt`은 **LocalDateTime**, 내부 payload 날짜는 **LocalDate**입니다. 실제 날짜 직렬화는 실행 검증하지 않았으며 아래는 ISO 형태의 설명용 예시입니다. 목록 API의 `NotificationResponse`(`payload`, 읽음 여부 등)는 이 구조와 다릅니다. 현재 경로/인증/목록 계약은 [SSE 가이드](../notification/SSE_NOTIFICATION_GUIDE.md)를 참고하세요.

## JSON 형식 코드

### 1. PROJECT_MY_APPLY (지원자 본인에게)

```json
{
  "type": "PROJECT_MY_APPLY",
  "data": {
    "receiverId": 6,
    "projectName": "React 프로젝트",
    "localDate": "2025-10-07"
  },
  "createdAt": "2025-10-07T12:00:00"
}
```

### 2. PROJECT_APPLY (프로젝트 소유자에게)

```json
{
  "type": "PROJECT_APPLY",
  "data": {
    "applicationId": 123,
    "projectId": 45,
    "receiverId": 3,
    "applicantId": 6,
    "applicantName": "김철수",
    "projectName": "React 프로젝트",
    "date": "2025-10-07"
  },
  "createdAt": "2025-10-07T12:00:00"
}
```

### 3. PROJECT_APPROVE (지원 승인 시)

```json
{
  "type": "PROJECT_APPROVE",
  "data": {
    "receiverId": 6,
    "projectId": 45,
    "approvalResult": "APPROVED",
    "date": "2025-10-07"
  },
  "createdAt": "2025-10-07T12:00:00"
}
```

### 4. PROJECT_REJECT (지원 거절 시)

```json
{
  "type": "PROJECT_REJECT",
  "data": {
    "receiverId": 6,
    "projectId": 45,
    "approvalResult": "REJECTED",
    "date": "2025-10-07"
  },
  "createdAt": "2025-10-07T12:00:00"
}
```

### 5. PROJECT_END (프로젝트 종료 시)

```json
{
  "type": "PROJECT_END",
  "data": {
    "projectId": 45,
    "memberId": 6,
    "projectName": "React 프로젝트",
    "occurredAt": "2025-10-07"
  },
  "createdAt": "2025-10-07T12:00:00"
}
```
